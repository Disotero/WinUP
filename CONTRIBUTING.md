# Как собрать и прислать правку

## Запуск из исходников

Нужны Windows 11 и PowerShell 5.1+.

- Точки входа — `.bat` в `0.1.1/windows-setup/` (сами запрашивают права администратора).
- Основная логика — `0.1.1/windows-setup/system/win11-setup.ps1`; перенос данных — `data-transfer.ps1`.
- Все настройки (список программ, службы, опции оптимизации, стресс-тест) — в начале `win11-setup.ps1`.
- Файлы сохраняйте в кодировке **UTF-8 с BOM**, иначе кириллица отображается некорректно.

## Сборка .exe

`system/build-exe.ps1` (PS2EXE) собирает лаунчеры с иконками. На GitHub — workflow `.github/workflows/build.yml` (вручную или по тегу `v*`).

## Правки

- **Issue** — для багов и идей. Приложите: версию Windows, режим запуска, вывод/лог (`system\logs\`) и, если удобно, «Отчёт для разбора» (ZIP с рабочего стола).
- **Pull request** — в отдельную ветку, с коротким описанием, что и зачем.
- Тестируйте на реальной или виртуальной Windows 11 — утилита меняет систему и работает с правами администратора.
