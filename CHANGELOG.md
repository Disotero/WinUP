# История изменений

Заметные изменения проекта. Новые версии — сверху.

## 0.1.1 — 2026-10-30

Переработан интерфейс в стиле Windows 11 (Fluent) и обновлена иконка.

### Интерфейс
- Окно настройки: боковое меню (Запуск / Оптимизация / Что будет) вместо вкладок, карточки режимов, опции переключателями, скругления, акцентный цвет, светлая/тёмная темы.
- «Перенос данных»: та же тема, плоские вкладки, акцентные кнопки, тёмные списки и журнал.
- Новая иконка WinUP (лягушка-ковбой) и парная иконка для «Переноса данных».

### Прочее
- Исправлена раскладка (контент не заходит под меню), прокрутка доходит до последней строки, «офлайн-папка» перенесена под строки раздела «Запуск».

## 0.1.0 — 2026-10-23

Первый публичный выпуск.

### Настройка Windows
- Режимы: «Всё», «Только программы», «Только оптимизация и очистка», «Только стресс-тесты».
- Установка программ (`winget`) и Microsoft Office, драйверы (Центр обновления, NVIDIA/AMD/Intel).
- Отключение телеметрии, рекламы, Copilot и лишних служб; удаление встроенного мусора.
- Твики (игровые, удобство, электропитание), регион/время/раскладки, максимальное разрешение и частота экрана, программы по умолчанию.
- Раздел «Оптимизация и очистка»: временный и системный мусор, сеть, ускорение + дополнительные опции.
- Стресс-тест (CPU/ОЗУ/GPU, температуры, WinSAT) и паспорт ПК (HTML).
- Офлайн-установка, подготовка к передаче ПК.

### Перенос данных
- Резервное копирование и восстановление файлов, закладок браузеров, сохранений игр, Telegram, Wi-Fi, списка ПО.
- Подключение библиотек Steam, перенос профильных папок на другой том.

### Интерфейс
- Графическое окно (WinUP): тёмная/светлая тема, вкладки, кнопки-плитки режимов, окно прогресса со статусами, диалоги вместо ввода в консоль.
- Сборка `.exe`-лаунчеров с иконками (PS2EXE) + автосборка на GitHub Actions по тегу.
