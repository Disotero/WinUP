# WinUP ⚙

**Автоматическая настройка чистой Windows 11: программы, драйверы, оптимизация, диагностика и перенос данных — в одном окне.**

WinUP — набор PowerShell-скриптов с графическим интерфейсом для постустановочной настройки Windows 11. За один проход ставит нужные программы и Microsoft Office, драйверы, отключает телеметрию и лишние службы, чистит и оптимизирует систему, прогоняет стресс-тест железа и формирует «паспорт ПК». Отдельный модуль переносит личные данные между компьютерами.

> ⚠️ **Хобби-проект.** Пишется под свои задачи и тестируется на реальных ПК. Работает, пользуюсь — но это не студийный продукт, баги возможны. Issue и pull request'ы welcome.
> Утилита работает **с правами администратора** и меняет систему; в начале автоматически создаётся точка восстановления, но запускайте осознанно.

## Скачать и запустить

Текущая версия — **0.1.0**.

1. Возьмите сборку из раздела [Releases](../../releases): **`Настройка Windows.exe`** и **`Перенос данных.exe`**. Либо используйте `.bat` из папки [`0.1.0/windows-setup`](0.1.0/windows-setup) — им сборка не нужна.
2. Запустите. Права администратора запрашиваются автоматически (UAC). Windows SmartScreen может предупредить о неизвестном издателе (exe не подписан) — «Подробнее» → «Выполнить в любом случае».
3. В окне выберите режим и нажмите **СТАРТ**. Ход работы показывается в отдельном окне прогресса; консоль по умолчанию скрыта.

Требования: Windows 11 (на других версиях — с ограничениями, выводится предупреждение), x64, права администратора.

## Что умеет

### Режимы

| Режим | Что делает |
|---|---|
| **Всё** | полная настройка: проверка системы, отключение служб и телеметрии, удаление встроенного мусора, установка программ и Office, драйверы, твики, оптимизация, паспорт ПК |
| **Только установка программ** | программы, Microsoft Office, программы по умолчанию |
| **Только оптимизация и очистка** | службы, дебloat, очистка мусора, сеть, ускорение — без установки ПО и драйверов |
| **Только стресс-тесты** | диагностика железа, изменения в систему не вносятся |

Флаги: со стресс-тестом · оптимизация и очистка · переустановка уже установленного · подготовка к передаче другому человеку · показывать консоль.

### Установка и настройка
- Программы через `winget` (список правится в конфиге), Microsoft Office, драйверы через Центр обновления и с сайтов NVIDIA/AMD/Intel.
- Отключение телеметрии, рекламы, Copilot и лишних служб; удаление встроенного мусора (Clipchamp, «Новости», Teams и т.п.).
- Твики: игровой режим, аппаратное планирование GPU, классическое контекстное меню, тёмная тема, электропитание; регион, время и раскладки.
- Максимальное разрешение и частота экрана; программы по умолчанию.

### Оптимизация и очистка
- Удаление временного и системного мусора (temp, кэш обновлений, логи, дампы, остатки обновлений ОС, `Windows.old`, корзина), сжатие хранилища компонентов.
- Безопасные сетевые настройки (сброс кэша DNS, снятие троттлинга; DNS-серверы не меняются).
- Ускорение: отключение фоновых приложений, обнуление задержки автозапуска, Storage Sense.
- Дополнительно по выбору: кэши браузеров, старые драйверы, гибернация, зарезервированное хранилище, OneDrive, SFC/DISM-проверка и др.

### Диагностика
- Проверка ОЗУ (частота против заявленной, XMP/EXPO), накопителей (SMART: износ, температура, ошибки), активации, UEFI/Secure Boot/TPM.
- Стресс-тест CPU/ОЗУ (7-Zip), GPU (FurMark), контроль температур и троттлинга, оценка WinSAT.
- **Паспорт ПК** — HTML-отчёт на рабочем столе (железо, состояние дисков, результаты тестов, замечания).

### Перенос данных
Отдельный модуль: резервное копирование и восстановление профильных папок, закладок браузеров, сохранений игр, Telegram, Wi-Fi, списка ПО; подключение библиотек Steam с других дисков; перенос профильных папок на другой том.

### Интерфейс
Тёмная/светлая тема, вкладки, кнопки-плитки режимов, живое окно прогресса со статусами (`OK / -- / !! / FAIL`), перезагрузка и диалоги — кнопками, а не в консоли.

## Безопасность и приватность

- Без телеметрии и аккаунтов; наружу ничего не отправляет.
- Наоборот — **отключает** телеметрию Windows, рекламу и Copilot.
- Перед изменениями создаёт **точку восстановления** (откат: `rstrui`).
- ⚠️ В режиме «Всё» по умолчанию отключаются автообновления Windows, а опционально — Защитник. После этого ПК уязвимее: держите сторонний антивирус и не открывайте файлы из непроверенных источников.

## Сборка .exe

`.bat` работают без сборки. Для запуска «как у программы» (иконка, двойной клик) собираются `.exe`-лаунчеры:

- **Локально:** `0.1.0/windows-setup/system/build-exe.ps1` (ПКМ → «Выполнить с помощью PowerShell») — установит PS2EXE и соберёт `Настройка Windows.exe` и `Перенос данных.exe` с иконками.
- **На GitHub:** `git tag v0.1.0 && git push origin v0.1.0` — workflow соберёт `.exe` и выложит их в Releases. Либо вручную: *Actions* → «Сборка .exe» → *Run workflow*.

Лаунчеры — тонкие (запускают `system\*.ps1`), поэтому правки логики не требуют пересборки `.exe`.

## Известные ограничения

- Рассчитано на **Windows 11**; на Windows 10 часть твиков не даёт эффекта (но не ломает).
- `.exe` не подписан сертификатом — SmartScreen будет предупреждать.
- Отключение Защитника и обновлений делает систему уязвимее — на ваш риск.
- Часть шагов опирается на поведение конкретных версий Windows и может измениться после обновлений системы.
