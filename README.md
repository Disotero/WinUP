# WinUP <img src="0.1.0/windows-setup/system/icon.png" height="34" align="top" alt="">


**Автоматическая настройка чистой Windows 11 — в одном окне.**

Программы, драйверы, оптимизация, диагностика железа и перенос данных за один проход. PowerShell + графический интерфейс (WinForms).

> ⚠️ Хобби-проект, тестируется на реальных ПК — баги возможны. Работает **с правами администратора** и меняет систему; в начале создаётся точка восстановления.

## Скачать

Версия **0.1.0**. Берите `.exe` из [Releases](../../releases) или `.bat` из [`0.1.0/windows-setup`](0.1.0/windows-setup) (сборка не нужна). Запуск — от администратора (UAC сам). SmartScreen может предупредить о неподписанном exe → «Подробнее» → «Выполнить в любом случае».

Требования: Windows 11, x64.

## Что умеет

| Режим | Что делает |
|---|---|
| **Всё** | службы, дебloat, программы + Office, драйверы, твики, оптимизация, паспорт ПК |
| **Только программы** | программы, Office, программы по умолчанию |
| **Только оптимизация** | очистка мусора, сеть, ускорение, службы — без установки |
| **Только стресс-тест** | диагностика железа, систему не меняет |

- **Настройка** — `winget`-программы и Office, драйверы (NVIDIA/AMD/Intel), отключение телеметрии/рекламы/Copilot, удаление встроенного мусора, игровые и системные твики.
- **Оптимизация** — чистка temp/кэша/логов/дампов/`Windows.old`, сжатие WinSxS, сеть и ускорение + опции (браузеры, драйверы, гибернация, SFC/DISM…).
- **Диагностика** — ОЗУ, диски (SMART), UEFI/TPM; стресс-тест CPU · GPU · память; паспорт ПК (HTML).
- **Перенос данных** — бэкап/восстановление файлов, закладок, сохранений игр, Telegram, Wi-Fi; библиотеки Steam; профильные папки на другой диск.
- **Интерфейс** — тёмная/светлая тема, вкладки, окно прогресса со статусами, диалоги вместо консоли.

## Безопасность

Без телеметрии и аккаунтов — наоборот, отключает слежку Windows. Перед изменениями делает точку восстановления (откат — `rstrui`). ⚠️ В режиме «Всё» отключаются автообновления (опционально — Защитник): держите сторонний антивирус.

## Структура

```
WinUP/
├── README · CHANGELOG · CONTRIBUTING · LICENSE
├── .github/workflows/        ← автосборка .exe
└── 0.1.0/windows-setup/
    ├── Настройка Windows.bat · Перенос данных.bat   ← запуск
    └── system/               ← скрипты, иконки, сборщик, техдокументация
```

Каждая версия — своя папка; `.exe` выкладываются в [Releases](../../releases) по тегу.

## Сборка .exe

Локально — `system/build-exe.ps1` (PS2EXE). На GitHub — `git tag v0.1.0 && git push origin v0.1.0` → сборка и Release.
