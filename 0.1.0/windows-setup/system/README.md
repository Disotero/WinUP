# WinUP — техническая документация

PowerShell-инструмент постустановочной настройки Windows 11. Графический интерфейс на WinForms, выполнение в одном процессе с вынесением длительных операций в отдельные runspace'ы.

## Состав каталога

```
windows-setup\
├── Настройка Windows.bat / .exe   — точка входа основного модуля
├── Перенос данных.bat    / .exe   — точка входа модуля переноса данных
└── system\
    ├── win11-setup.ps1            — основной модуль (установка, оптимизация, тесты, GUI)
    ├── data-transfer.ps1          — модуль переноса данных
    ├── launcher-setup.ps1         — лаунчер для сборки «Настройка Windows.exe»
    ├── launcher-transfer.ps1      — лаунчер для сборки «Перенос данных.exe»
    ├── build-exe.ps1              — сборка .exe-лаунчеров через PS2EXE
    ├── icon.ico / icon.png        — иконка приложения
    ├── icon-db.ico / icon-db.png  — иконка модуля переноса данных
    ├── README.md                  — этот файл
    ├── version.txt                — версия программы (единый источник для сборки .exe)
    ├── offline\                   — офлайн-кэш (создаётся сборщиком)
    └── logs\                      — логи, итоги стресс-тестов, копии паспортов
```

Запускаются только точки входа из `windows-setup\` (`.bat` или `.exe`). Прямой запуск `win11-setup.ps1` также допустим — модуль самостоятельно запрашивает повышение прав.

## Точки входа и сборка .exe

`.bat` работают без предварительной подготовки. Для запуска с иконкой приложения собираются `.exe`-лаунчеры: на машине с Windows выполнить `system\build-exe.ps1` (ПКМ → «Выполнить с помощью PowerShell»). Скрипт устанавливает модуль PS2EXE из PowerShell Gallery и компилирует `Настройка Windows.exe` (иконка `icon.ico`) и `Перенос данных.exe` (иконка `icon-db.ico`) с манифестом `requireAdmin`. Лаунчеры — тонкие: определяют свой каталог и запускают соответствующий `.ps1` из `system\`; логика в них не встроена, поэтому правки скриптов не требуют пересборки `.exe`. `.bat` сохраняются как резервная точка входа.

## Графический интерфейс

Стартовое окно (`WinUP`): переключатель светлой/тёмной темы (по умолчанию тёмная) и три вкладки.

- **Запуск** — выбор режима (плитки) и флаги.
- **Оптимизация** — дополнительные параметры очистки и оптимизации.
- **Выбранное** — список операций, формируемый по текущему режиму и флагам.

Консоль по умолчанию скрыта; ход выполнения отображается в отдельном окне прогресса (текущий этап, индикатор, список результатов). Подробный лог в консоли включается флагом «Показывать окно консоли».

### Режимы

| Режим | Состав |
|---|---|
| **Всё** | полная настройка: проверка, службы, дебloat, установка ПО и драйверов, твики, оптимизация, паспорт |
| **Только установка программ** | программы, Office, программы по умолчанию |
| **Только оптимизация и очистка** | службы, дебloat, очистка, сеть, ускорение — без установки ПО и драйверов |
| **Только стресс-тесты** | диагностика оборудования, изменения в системе не вносятся |

### Флаги

- **Со стресс-тестом** — добавляет блок диагностики (принудительно включён в режиме «Стресс-тест»).
  - **Удалить программы для тестов после** — удаление ПО, установленного только для тестов (FurMark, 7-Zip); установленное ранее не затрагивается.
- **Оптимизация и очистка** — включает одноимённый этап (доступен в режиме «Всё»).
- **Переустановить уже установленные программы** — при выключенном флаге имеющееся ПО пропускается.
- **Подготовить для передачи другому человеку** — см. раздел «Передача ПК».

Кнопка **СТАРТ** выводит сводку операций и предупреждения перед запуском. Для не-Windows 11 отображается предупреждение о неполной совместимости.

## Конвейер основного модуля

Порядок этапов (часть пропускается в зависимости от режима и флагов):

1. **Подготовка** — точка восстановления; в фоновых runspace'ах запускается загрузка драйвера GPU и дистрибутива Office; синхронизация времени; сводка оборудования.
2. **Проверка системы** (только чтение): частота ОЗУ против заявленной (XMP/EXPO), конфигурация модулей; состояние накопителей по SMART (износ, температура, наработка, ошибки); активация, UEFI/Secure Boot/TPM 2.0, свободное место.
3. **Отключение защиты** (по умолчанию выключено): Defender/SmartScreen/UAC — при отключённой «Защите от подделки».
4. **Службы и телеметрия**: отключение служб из `$Services`, политики телеметрии, рекламного идентификатора, Consumer Features, Copilot.
5. **Удаление предустановленного ПО** (`$Bloatware`): Appx-пакеты для всех пользователей и из образа.
6. **Установка программ** (`winget`, последовательно) и Microsoft Office.
7. **Обновление драйверов** через Windows Update.
8. **Драйвер GPU** с сайта производителя (NVIDIA — тихая установка; AMD — официальный установщик; Intel — DSA).
9. **Экран**: максимальное разрешение и частота обновления на каждом мониторе.
10. **Регион и время**: часовой пояс, синхронизация, раскладки и сочетание переключения; применяется к экрану входа и новым профилям.
11. **Твики**: игровой режим, аппаратное планирование GPU, отключение Game DVR и акселерации мыши; классическое контекстное меню, показ расширений, отключение рекламы в «Пуск», тёмная тема.
12. **OneDrive / Edge / ИИ-функции**: отключение автозапуска и навязчивых окон; отключение Recall, Click to Do, ИИ в Paint и «Блокноте».
13. **Программы по умолчанию** (`$DefaultApps`) — через официальный механизм ассоциаций (применяется после следующего входа).
14. **Электропитание**: на десктопе — «Высокая производительность», отключение сна и гибернации; на ноутбуке — «Сбалансированная».
15. **Отключение автоматических обновлений Windows.**
16. **Стресс-тест** (опционально) — см. ниже.
17. **Оптимизация и очистка** — см. ниже.
18. **Паспорт ПК** — HTML-отчёт на рабочем столе, открывается в браузере.

Индикатор в заголовке/окне прогресса показывает номер этапа и общий процент (взвешенный по длительности). По завершении — звуковой сигнал и диалог с итогом и предложением перезагрузки.

## Оптимизация и очистка

Этап включается флагом «Оптимизация и очистка» (режим «Всё») либо режимом «Только оптимизация». Безопасные операции выполняются всегда:

- **Очистка**: временные файлы (текущего и всех пользователей), кэш Windows Update, логи CBS/DISM/Panther, дампы (Minidump, MEMORY.DMP), WER, остатки обновлений ОС (`$WINDOWS.~BT/~WS`, `$GetCurrent`), `Windows.old`, корзина, кэш эскизов, Delivery Optimization; `DISM /StartComponentCleanup`.
- **Сеть** (без изменения DNS-серверов — совместимо с VPN): сброс кэша DNS, снятие мультимедийного троттлинга (`NetworkThrottlingIndex`), отключение засыпания сетевого адаптера (на десктопе).
- **Ускорение**: отключение фоновых приложений, обнуление задержки автозапуска, включение Storage Sense.

Дополнительные параметры (вкладка «Оптимизация», по умолчанию выключены): кэши браузеров; удаление устаревших драйверов в DriverStore; отключение гибернации (десктоп); отключение «Зарезервированного хранилища»; полное удаление OneDrive; дополнительные службы (`$ExtraServices`); визуальные эффекты на производительность; проверка и восстановление системных файлов (`DISM /RestoreHealth` + `sfc`); очистка истории (недавние, RunMRU, буфер) для передачи ПК; предельное сжатие WinSxS (`/ResetBase`, **необратимо**).

В конце этапа выводится объём освобождённого места.

## Параллелизм и устойчивость

- В фоне (параллельно этапам 1–6): загрузка драйвера GPU и дистрибутива Office.
- Установка ПО — строго последовательная (параллельная установка приводит к сбоям установщиков, в т.ч. Office с кодом 1603).
- Сетевые операции выполняются с 2–3 повторами при сбоях.
- Длительные операции вынесены в отдельные runspace'ы; окно прогресса остаётся отзывчивым (`DoEvents`).

## Индикация результата

Каждая операция логируется строкой статуса:

```
[ OK ] Google Chrome — установлен
[ -- ] 7-Zip — уже установлен
[ !! ] FurMark — тест прерван
[FAIL] VLC — ошибка установки  (код 0x8A150011)
```

`OK` — успех; `--` — не требовалось; `!!` — частично; `FAIL` — ошибка (причина в скобках).

Дополнительно по завершении:
- **«Что сделать руками»** — действия, недоступные для автоматизации (например, драйвер AMD, включение XMP); дублируется в паспорте.
- **Повтор неудачных установок** — при сбоях предлагается переустановить только затронутое ПО.
- **«Отчёт для разбора»** — ZIP на рабочем столе (лог, итог стресс-теста, паспорт, сведения о системе).

Подробный лог: `system\logs\setup-log_<дата>.txt`.

## Стресс-тест

- **CPU/ОЗУ**: встроенный тест 7-Zip, несколько проходов (`$StressPasses`).
- **GPU**: FurMark (`Geeks3D.FurMark.2`), по умолчанию 180 с (`$GpuStressSeconds`), контроль сброса видеодрайвера.
- **Температуры/троттлинг**: LibreHardwareMonitor + драйвер PawnIO; фиксируются максимальные температуры CPU/GPU и факт снижения частоты.
- **Проверка ОЗУ**: встроенная диагностика памяти Windows на следующую перезагрузку (результат — на этапе «Проверка системы» при следующем запуске).
- **Оценка WinSAT** и итоговое окно: результаты, стабильность, сравнение CPU (`$CpuReference`) и ориентировочная пригодность для игр (`$GameTiers`).

Итог: `system\logs\stress-test_<дата>.txt`. Инструменты скачиваются при отсутствии.

## Перенос данных (`data-transfer.ps1`)

GUI с четырьмя вкладками.

1. **Сохранить** — на внешний том, структура `Перенос данных\<пользователь>\<дата_время>\<категория>\`: профильные папки, закладки браузеров и профиль Firefox, сохранения игр (`$GameSaves`), Telegram (сессия без кэша), ключи SSH, профили Wi-Fi с паролями (открытым текстом), список ПО (`winget.json`), сетевые диски и принтеры. По завершении — верификация по категориям и `отчёт.txt`.
2. **Восстановить** — выборочное восстановление; браузеры и Telegram закрываются; более новые файлы не перезаписываются; опциональная установка ПО из сохранённого списка. Пароли браузеров привязаны к старой системе и переносятся синхронизацией/экспортом.
3. **Игры Steam** — поиск библиотек на всех томах и регистрация в Steam без перекачивания.
4. **Папки на другой диск** — перенос профильных папок на другой том с сохранением точек.

Инкрементальное докопирование включено по умолчанию. Исключения — `$ExcludeDirs` / `$ExcludeFiles`.

## Офлайн-установка

1. **Сборка кэша** (на машине с интернетом): ссылка «Собрать офлайн-папку» в стартовом окне. В `system\offline` загружаются программы и FurMark (`winget download`, ~1,5 ГБ), Office (~3–4 ГБ), базовые драйверы текущего ПК (`pnputil /export-driver`), драйвер NVIDIA (~0,7 ГБ). Требуется `winget` ≥ 1.8. Путь без кириллицы (установщик Office чувствителен к пути).
2. **Установка**: скопировать `windows-setup` с `offline` на целевую машину и запустить как обычно. В стартовом окне — индикатор офлайн-режима. ПО ставится из кэша; драйверы — из `offline\drivers` (Windows выбирает подходящие); NVIDIA — из `offline\gpu\nvidia`, AMD — из `offline\gpu\amd` (вручную).

## Передача ПК

Флаг «Подготовить для передачи другому человеку». Пользовательские настройки дублируются в профиль по умолчанию. По завершении и повторном входе выполняется `sysprep /oobe` с выключением; после первого входа нового владельца техническая учётная запись удаляется (`$ClientRemoveTechUser`). Несовместимо с активным BitLocker.

## Конфигурация

Параметры в начале `win11-setup.ps1`:

- **`$Apps`** — список программ (`winget`-ID); **`$DefaultApps`** — ассоциации по умолчанию; **`$StartupBlock`** — автозагрузка.
- **`$Services`** / **`$ExtraServices`** — отключаемые службы; **`$Bloatware`** — удаляемые Appx.
- **`$OfficeProduct` / `$OfficeApps` / `$OfficeLanguage`** — конфигурация Office.
- **`$Do*`** — включение/отключение этапов; **`$OptDefaults`** — параметры этапа оптимизации.
- **`$TimeZone` / `$Languages` / `$LayoutHotkey` / `$MonitorOffMinutes`** — регион, раскладки, экран.
- **`$StressPasses` / `$GpuStressSeconds` / `$CpuReference` / `$GameTiers`** — параметры стресс-теста.
- **`$DisableFirewall`** (по умолчанию `$false`), **`$UiTheme`** (`dark`/`light`), **`$ShowConsole`**.

Файл сохраняется в кодировке **UTF-8 с BOM** (иначе кириллица отображается некорректно).

## Примечания

- Защитник отключается только при выключенной «Защите от подделки»; иначе — `[FAIL]` с инструкцией.
- Часть служб и задач обновлений защищена системой; отключается в пределах допустимого, остальное помечается `[FAIL]`/`[ !! ]`.
- Office устанавливается с сервера Microsoft; требуется лицензия (вход при первом запуске).
- Откат — точка восстановления «Перед win11-setup» (`rstrui`).
- После отключения Defender и обновлений рекомендуется сторонний антивирус и осторожность с непроверенными файлами.
